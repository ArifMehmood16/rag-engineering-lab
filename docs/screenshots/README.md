## Refresh the images

1. Install with `bun install --frozen-lockfile` and run `bun run dev`.
2. Use a desktop viewport of 1440 × 900 and a narrow viewport of 390 × 900. Capture the page viewport as JPEG, preserving the app header, controls, current card, and result strip.
3. For the overview, start a fresh lab load and keep the introduction centred. Wait for the scene to render. Choose **Answer a question** and keep its introduction centred for the question-map image.
4. For the index, choose **Build knowledge** and scroll to **Index · the result**. Wait for the camera to settle and verify the full globe, passage tiles, vector values, source metadata, and output labels have appeared. Pause ambient motion only after confirming readiness; inspect the frame again before saving.
5. For prefix reuse, open **Caching** and scroll to **Request 2 · reuse the prefix**.
6. For evaluations, open **Evals** and keep **Start with reviewed test cases** centred. Let a labelled packet leave its source before capturing so motion is evident without covering fixed labels.
7. Use the visible motion control to pause a useful frame if needed. Never change fixture scores, counters, labels, or scene state just to improve a screenshot.
8. Replace the relevant JPEGs, verify all relative image links from the README, and inspect the images at normal reading size.

The screenshots intentionally show a local demonstration, not evidence of real provider performance. Avoid including editor panels, credentials, private browser content, or unrelated application windows.
